# GTA VI Companion

Application compagnon personnelle pour GTA VI (PC + Android), en français, conçue autour de la protection anti-spoiler.

- `docs/01-audit-architecture-plan.md` : audit des sources, architecture, plan.
- `backend/` : base SQLite (migrations), moteur anti-spoiler, tests.

```bash
cd backend && python3 -m pytest -q
```
